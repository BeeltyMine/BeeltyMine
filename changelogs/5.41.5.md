# 5.41.5
Released 6th April 2026.

This release fixes powder snow bucket placement targeting on existing powder snow blocks.

## Fixed
- Fixed powder snow bucket behavior when clicking existing powder snow blocks. The bucket now places into the adjacent target block (for example, the block above when clicking the top face) instead of rewriting the clicked powder snow block.
- Preserved replace-in-place behavior for thin replaceable targets like snow layer and leaf litter.

## Changed
- Bumped BASE_VERSION to 5.41.5.
