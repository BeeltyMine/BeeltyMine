# 5.41.6
Released 12th April 2026.

This release introduces crossbow gameplay support with full registry, enchantment, event, and network integration.

## Added
- Added a new `Crossbow` item implementation with charging, shooting, durability consumption, and charged-state NBT persistence.
- Added multishot firing behavior (three-arrow spread) and quick-charge timing support.
- Added `EntityShootCrossbowEvent` so plugins can inspect, modify, or cancel crossbow projectile spawns.
- Added crossbow loading and shooting sounds for client-side feedback.
- Added a charged-item completion actor event path in network session handling.
- Added crossbow registration and parsing wiring across item inputs, string parser, generated vanilla item accessors, serializer/deserializer mapping, and item type IDs.
- Added enchantment support for `MULTISHOT` and `QUICK_CHARGE` across vanilla enchantment inputs, availability/tag rules, parser aliases, generated accessors, and Bedrock ID mapping.

## Changed
- Updated item use flow to support chargeable items through per-tick charge progression without incorrectly consuming the held item on click-air handling.
- Added the new item-level `continueUsing()` hook and chargeable contract used by crossbow charging.
- Bumped BASE_VERSION to 5.41.6.

## Notes
- Crossbows currently load and fire arrows. Firework rocket loading is not included in this release.
