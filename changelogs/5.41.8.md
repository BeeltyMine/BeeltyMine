# 5.41.8
Released 12th April 2026.

This release adds Beelty chemistry feature toggles controlled by beelty.yml and ensures safe startup and mapping behavior when chemistry content is disabled.

## Added
- Added runtime bootstrap of beelty.yml in the server data folder, matching pocketmine.yml creation behavior.
- Added centralized Beelty feature flags for `chemistry.items` and `chemistry.blocks`.

## Changed
- Chemistry block registrations are now conditional on `chemistry.blocks`.
- Chemistry item registrations are now conditional on `chemistry.items`.
- String parser aliases for chemistry blocks and items are now registered only when their corresponding chemistry feature is enabled.
- Bedrock chemistry block mappings and chemistry item serializer/deserializer mappings are now conditionalized to match feature flags.
- Ice bomb break particle fallback now uses snowball visuals when chemistry items are disabled.
- Bumped BASE_VERSION to 5.41.8.
- Lowered per-run cyclic garbage collector logging from info to debug to prevent console spam during normal operation.
- Added `BeeltyFeatureGate` as a centralized gate class for feature-flag-controlled registration callbacks.
- Refactored chemistry item registration in `VanillaItems` and `VanillaItemsInputs` to use centralized gating helpers instead of repeated inline `if` blocks.
- Bumped BASE_VERSION to 5.41.8.

## Fixed
- Fixed potential startup and runtime failures caused by chemistry content references when chemistry flags are disabled in beelty.yml.
