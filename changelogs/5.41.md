# 5.41.1
Released 25th March 2026.

This is a support release for Minecraft: Bedrock Edition 1.26.10.

## General
- Added support for Minecraft: Bedrock Edition 1.26.10.
- Added azalea and bamboo-related block support, including azalea tree generation updates.
- Updated block, item, effect and enchantment registry input sources used by generated registries.
- Renamed bundled server config resource from `resources/core.yml` to `resources/pocketmine.yml`.
- Updated startup/info and garbage-collector logging flows.
- Updated dependency/tooling setup in Composer for the Bedrock 1.26.10 protocol/data stack.
- Removed support for earlier Bedrock versions.

## Fixes
- Added an experimental soft limit of 512 characters for writable book pages to prevent oversized page content.
- Improved player skin handling and synchronization across login/session flow.
- Fixed several gameplay edge cases, including respawn-anchor item-consumption behavior and Frosted Ice silk-touch behavior.

## Internal and cleanup changes
- Removed a large set of legacy/custom modules (including older command, entity, crafting/trading and weather-related internals).
- Refactored packet handling and registry utilities for cleaner network and serialization paths.
