# 5.42.8
Released 6th May 2026.

This release updates BeeltyMine to Minecraft Bedrock 1.26.20 support and fixes the client-side world loading issue that could leave players in a broken empty/partial render state after joining.

## Added
- Updated `pocketmine/bedrock-data` and `pocketmine/bedrock-protocol` to `dev-bedrock-1.26.20`.
- Regenerated Bedrock data constants and registry mappings for the new 1.26.20 data set.

## Changed
- Updated protocol, block palette, item registry, and generated data files to match Bedrock 1.26.20.
- Adjusted inventory packet handling to match the 1.26.20 `InventorySlotPacket` storage semantics.
- Updated changelog and codegen scripts to the current repository layout.

## Fixed
- Fixed players entering the world without the terrain loading correctly after login.
- Fixed data/protocol mismatch caused by mixing 1.26.20 protocol code with 1.26.10 Bedrock data files.
- Fixed inventory slot sync behavior so client item updates use the correct optional storage/container payload.
